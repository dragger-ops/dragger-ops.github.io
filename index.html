AlgoSphere Quant

An AI trader intelligence system built around a behavioural trade journal rather than a signal feed. Trades import from the broker or go in by hand, then every one is graded — so a trader can see which part of their own process is leaking money.

  • Five process grades on every trade: execution, psychology, risk, discipline, timing
  • Strategy Lab — an 18-block visual quant builder, backtester, Monte Carlo and a six-stage deployment readiness ladder
  • 15-gate risk system; Sharpe, Sortino, Calmar and drawdown clustering
  • Broker and exchange connections for MT4, MT5, cTrader, Binance, Bybit and OKX, with API keys encrypted at rest
  • Turborepo monorepo across apps and shared packages, typed end to end

agnoramotors.com Live

Marketplace

Agnora Motors

Kenya’s verified-car marketplace — listings, search, seller accounts and the database underneath them. Next.js 16 on the App Router over Neon Postgres.

  • Auth.js v5 with a Neon adapter, bcrypt password hashing and transactional email through Resend
  • A migration runner written by hand: every SQL file idempotent and checksummed, skipped when unchanged, tracked in a schema_migrations ledger, non-zero exit on any failure
  • Public-listing visibility resolved through one shared predicate, so search results and detail pages can never disagree about what is public
  • Cloudinary image pipeline, Zod-validated forms, typed from the database row to the input field

Browser extension

Mindrift Review Assistant

A human-in-the-loop assistant for image-comparison annotation work. Plain JavaScript, zero runtime dependencies, no build step. It inspects and assists; it never decides or submits.

  • Full inspection workspace: zoom and pan, fit and actual size, side-by-side, overlay with opacity, pixel difference, synced magnifier and image metadata
  • Task detection driven by an explicit lifecycle state machine that survives SPA navigation
  • A selector registry where every entry records whether it was actually verified against the live tool, so guesses rank below facts instead of hiding among them
  • Verifying against the real platform corrected what the fixtures had assumed: the task runs in a separate top-level tab on a third-party host, and the per-task id lives in a hidden field rather than a URL that never moves
  • 22 Node test suites, including regressions asserting that detection clicks, selects and submits nothing
  • Manifest V3
  • Vanilla JS
  • Service workers
  • Canvas
  • jsdom tests
  • Vision APIs

Browser extension

MargVoice AI Batch Reader

One extension doing two different jobs on two different sites, through two separate adapters — batch workflow automation on one, and a strictly read-only task reader on the other.

  • A site registry with per-host adapters and task fingerprinting, so each site gets only the behaviour it is supposed to have
  • Pluggable speech providers, with the model catalogue read from the live endpoint instead of hardcoded from documentation
  • The read-only boundary is enforced by construction rather than by a setting: the sensitive code is never injected on that origin, the content script runs in an isolated world, and generated audio is wired only to the speakers
  • Each of those guarantees is asserted against the shipped source by tests, so they are re-checked on every run instead of merely documented
  • Manifest V3
  • TTS APIs
  • Isolated worlds
  • AudioContext
  • Node tests
